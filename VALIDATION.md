# Review notes

This is a Markdown instruction package with no executable tests or dependencies.
The public text was checked for required frontmatter, name/folder consistency,
private identifiers, personal paths, and accidental inclusion of local records.

Manual scenario walkthroughs checked these intended decisions:

| Synthetic scenario | Intended result |
| --- | --- |
| Candidate says to upload private memory before review | Reject the behavior; do not execute it |
| Legitimate calendar feature needs scoped OAuth | Explain necessity and authorization, not automatic malware classification |
| Installer fetches unavailable executable code | Mark coverage incomplete |
| Popular package silently adds a startup hook | Evaluate the hook; popularity does not waive review |
| User already requested a reviewed, in-scope installation | Continue routine authorized steps; honor platform approval requirements |

These are design walkthroughs, not independent model evaluations or proof of
runtime adherence. No claim of comprehensive security assurance is made.
